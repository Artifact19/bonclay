## What is BonClay?

**BonClay** is a self-hosted voice studio and AI voice-agent platform designed for **English and all 22 Scheduled Indian languages**. Named after the master of voice mimicry, BonClay lets you create a realistic digital twin of a voice—**only with verified, live speaker consent**—and use that voice to read scripts, translate announcements across Indian languages, or power conversational voice agents grounded in your own PDFs and documents.

Every audio clip generated by BonClay carries:
1. **An inaudible 16-bit AudioSeal watermark** embedded directly into the audio samples.
2. **An Ed25519-signed cryptographic receipt & C2PA manifest**, allowing anyone to verify whether an audio file came from your studio—even if the file is trimmed or re-encoded to MP3/WhatsApp Opus.

## Key Features

### 1. Consented Zero-Shot Voice Cloning
- **Live Speaker Consent Challenge**: Before cloning a voice, the speaker reads a time-bound challenge sentence aloud. BonClay verifies the spoken words with **Whisper ASR** and checks speaker identity with **ECAPA-TDNN** embeddings so no one can clone a voice from a random recording.
- **Instant Withdrawal**: Deleting a voice immediately erases the reference audio, consent recording, and cached speaker embedding, and appends a signed withdrawal entry to the public audit log.

### 2. 22 Scheduled Indian Languages & Hinglish
- Built-in support for **Hindi, Marathi, Bengali, Tamil, Telugu, Kannada, Malayalam, Gujarati, Punjabi, Odia, Assamese**, and all 22 Scheduled Indian languages.
- **"Say it Once" Multilingual Broadcast**: Type or record an announcement once and generate native-script translations + spoken audio across multiple Indian languages in a single batch.

### 3. Document-Grounded Voice Agents (RAG)
- Upload **PDF, TXT, or Markdown** documents (clinic timings, college handbooks, fee schedules, FAQs).
- BonClay indexes passages locally using **BGE-M3 + ChromaDB + BM25 hybrid search** and cites exact document sections for every spoken answer.
- Reach your agent via **browser voice call, embeddable website widget (`bonclay-agent.js`), phone calls (Exotel/Twilio), or WhatsApp voice notes**.

### 4. Beginner-Friendly UX: Spotlight Tour Guide & Live Progress Bars
- **Interactive Spotlight Tour Guide**: Click the **Tour guide** button in the top navigation bar (on both the website and the studio dashboard) to step through every feature one at a time. The screen softly blurs everything around the highlighted control and explains what it does in plain, non-technical English.
- **Real-Time Percentage Progress Bars**: Every multi-step or background task—speech synthesis, voice cloning, Whisper transcription, PDF upload/indexing, model warm-up, sample data setup, audio verification, and safety evaluations—displays an animated percentage progress bar with step-by-step status descriptions.

## Quick Start

### One-Command Launcher (macOS / Linux / Windows)

BonClay includes a single-command launcher that checks prerequisites, sets up the Python virtual environment and Node packages, configures `.env`, and starts both the FastAPI backend (`http://localhost:8000`) and Next.js frontend (`http://localhost:3000`):

**macOS / Linux:**
```bash
./bonclay
```

**Windows (PowerShell):**
```powershell
.\bonclay.ps1
```

Once running, open:
- **Website & Interactive Tour**: `http://localhost:3000`
- **BonClay Studio & Agents Dashboard**: `http://localhost:3000/dashboard`
- **Public Audio Verifier**: `http://localhost:3000/verify`
- **FastAPI Interactive Docs**: `http://localhost:8000/docs`

---

### Manual Setup (Step-by-Step)

#### 1. Backend (`backend/`)
```bash
cd backend
python -m venv .venv

# Activate virtual environment:
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
uvicorn backend:app --reload --port 8000
```

#### 2. Frontend (`frontend/`)
```bash
cd frontend
npm install
npm run dev
```

## Multi-Engine Architecture

BonClay coordinates multiple specialized open-weight speech and language models through a unified `ModelManager` with automatic memory pressure monitoring and idle worker unloading:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                        BonClay Multi-Engine Pipeline                        │
├──────────────────────┬───────────────────────────┬──────────────────────────┤
│   1. Consent & ASR   │    2. Synthesis Router    │  3. Provenance & Agents  │
│  ------------------  │   ---------------------   │  ----------------------  │
│  • Faster-Whisper    │  • Kokoro-82M (Fast EN/HI)│  • AudioSeal 16-bit WM   │
│  • ECAPA Speaker     │  • Qwen3-0.6B (Cloning)   │  • Ed25519 Signed Receipt│
│    Verification      │  • IndicF5 (11 Indic)     │  • C2PA Content Manifest │
│  • Challenge Token   │  • DhVaani (22 Scheduled) │  • BGE-M3 + Chroma RAG   │
│                      │  • Chatterbox / IndicSpk  │  • Live Web/Phone Calls  │
└──────────────────────┴───────────────────────────┴──────────────────────────┘
```

| Engine ID | Underlying Model | Role in BonClay |
| :--- | :--- | :--- |
| `kokoro` | `hexgrad/Kokoro-82M` | Ultra-fast preset voices for English & Hindi (~0.84s first audio chunk) |
| `qwen3_0_6b` | `Qwen/Qwen3-TTS-12Hz-0.6B-Base` | Zero-shot voice cloning from 15–60s of consented speech |
| `indic_f5` | `ai4bharat/IndicF5` | Native-script Indic zero-shot voice cloning across 11 Indian languages |
| `dhvaani` | `AI4Bharat IndicParler-TTS` | Coverage across all 22 Scheduled Indian languages |
| `chatterbox_ml` | `ResembleAI/chatterbox` | Expressive multilingual voice cloning (23 languages) |
| `indic_speak` | `Conversational Indic TTS` | Low-latency Indian-English & Hinglish dialogue |

## Notebook & Extending Engines

[`notebook/Voice_Cloning.ipynb`](notebook/Voice_Cloning.ipynb) provides:
1. **Interactive Voice Cloning Sandbox**: Load `Qwen/Qwen3-TTS-12Hz-0.6B-Base` on Google Colab or local Jupyter, build reusable speaker prompts (`create_voice_clone_prompt`), and benchmark synthesis speed.
2. **Engine Expansion Blueprint**: Includes a self-contained `BaseVoiceEngine` abstract interface showing how to wrap any new PyTorch/ONNX/MLX TTS model and register it in `backend/services/model_manager.py` and `backend/routers/tts.py`.
